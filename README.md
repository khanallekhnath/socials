# User-content
User &amp; content APIs.


# Install ruby
```
$ ruby -v
$ ruby 3.4.10 (2026-06-30 revision 2b0b7728dc) +PRISM [arm64-darwin25]
rails-8.1.3
```

## Create new application
Since, we don't need any client dependent features, api application is sufficient for the time being. Rails used sqlite3 by default.

`rails new socials --api --database=postgresql`

# Docker
Copy `.env.sample` to `.env` and update the credentials.
`Dockerfile` for production(generated by `rails new` command). `Dockerfile.dev` for development along with `docker-compose.yml`

# Active Record Serializer
Add `active_model_serializers` gem to the Gemfile. This is targeted for development & tests only for now. The `Gemfile.lock` needs to be updated, otherwise, it will see differences and will add that gem.
> docker compose run --rm app bundle install

Generate the serializer
> docker compose run --rm app bundle install

# Active Record Seed
> Prefer `railse db:prepare` over `rails db:migrate` or something similar. `db:prepare` is kind of a composit action. Still needed to run `db:seed`!
